# scratch

This directory holds working and experimental scripts that were used during
development (benchmarking snippets, one-off result-generation and
report-embedding utilities, etc.) but were never organized into the curated
topic-folder examples (`examples/architectures/`, `examples/geometry/`, and
so on). They may be less polished, less documented, or narrower in scope than
the rest of `examples/`, and some assume they're run from the repository
root with the project installed in editable mode — treat them as reference
material rather than supported, maintained examples.
